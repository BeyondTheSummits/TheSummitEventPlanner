The Summit Event Planner
A console-based Python application designed to help users plan events, manage expenses and compare costs against an available budget.

The Summit Event Planner allows users to enter a budget and track a range of event-related expenses including venue, staffing, catering, entertainment, production, logistics and insurance costs. The system automatically calculates the total event cost and provides instant feedback on whether the event is under budget, over budget or exactly on budget.

This project was developed as part of my software development learning journey and demonstrates core Python programming concepts such as functions, loops, input validation, calculations and decision making.

How It Works
The user enters their available budget.
The system requests event expenses for multiple categories.
The application calculates the total event cost.
The budget is compared against the total cost.
The user receives one of the following outcomes:
Under Budget (shows how much)
Over Budget (shows how much)
Exactly On Budget
The user can choose to perform another calculation.
